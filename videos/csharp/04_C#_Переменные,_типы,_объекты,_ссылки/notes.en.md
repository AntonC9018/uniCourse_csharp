# Variables, types, objects, and references

[00:00:00](https://www.youtube.com/watch?v=wjsV9CvZfGI&t=0s) This lesson teaches you to predict what a short C# program prints by tracking what each variable holds. Start with one number, overwrite it, then build a memory model for numbers and strings. Finally, copy one variable into another and ask whether changing the source also changes the destination.

The terms you will need are:

- **Variable, identifier, and memory cell:** a variable is a named storage location; its identifier is its name in the program; a memory cell is the box used to draw that storage.
- **Value and type:** a value is the information stored or copied. A type specifies what kind of value is allowed. `int` represents whole numbers, `double` represents floating-point numbers, and `string` represents text.
- **Declaration and initialization:** a declaration introduces a variable with its type and name; initialization supplies its first value.
- **Assignment and reading:** assignment writes a value into a variable; reading obtains its current value. Assignment uses `=`, with the destination on the left.
- **Statement and literal:** a statement is an instruction in the program; a literal writes a value directly in source code, such as `123` or `"hello"`.
- **Compiler and runtime:** the compiler checks and translates source code; the runtime supports the executing program and manages its memory.
- **Stack and heap:** the stack is the temporary memory area used for local-variable boxes in this lesson's drawings. The heap is dynamic memory used for objects, also called *куча* in the recording.
- **Object, address, and reference:** an object is an instance containing data; an address describes a place in memory; a reference lets the program reach an object. The drawings represent references as object addresses.
- **Value type and reference type:** a value-type variable contains the value itself; a reference-type variable contains a reference to an object.
- **Class:** a kind of type whose instances are objects; variables of class types hold references to those instances.
- **Console output and function call:** console output is text displayed by the program. A function call asks an operation to run; `Console.WriteLine(...)` writes the supplied value's text representation and ends the line.

A few accuracy terms appear in the clarifications below, rather than as additional topics taught in the video:

- **Immutability:** an existing string object's characters cannot be changed.
- **Garbage collection:** automatic memory management that can reclaim unused objects and move surviving objects while updating references.
- **String interning:** reuse of a string object for matching text; a literal need not allocate a fresh object each time its line executes.
- **Pointer and address-of notation:** a pointer represents a memory address. C#'s `&` operator takes a variable's address under pointer rules; it is not a general way to obtain a string object's managed reference.
- **Boxing and overload:** boxing converts a value-type value to an object containing a copy. An overload is a version of a function accepting particular parameter types.
