- `Debug.Assert` is development-only: once the program is written and tests pass, the compiler omits the assert call from the compiled program (TP-035, transcript 06:33–06:45). - Public library contracts therefore use an argument exception: it survives the release build and turns caller misuse into a clear error at the call site instead of a confusing failure later (TP-040, transcript 07:23–07:43).
